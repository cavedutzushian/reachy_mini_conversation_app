# Feature Specification: RAG 模型下載與單文件離線產包

**Feature Branch**: `feat/005-prepare-rag-assets`

**Created**: 2026-11-06

**Status**: Draft

**Input**: User description: "加入一支只處理 TXT／Markdown、輸出既有合約格式的離線產包腳本，還有一個自動下載指定模型到正確路徑的腳本。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 下載一次即可離線使用的指定模型 (Priority: P1)

部署者手動執行下載腳本，指定 BGE-M3 的固定版本，即可把既有文件工具所需的完整模型放到預設位置，不必自行挑選、搬移或修補檔案。

**Why this priority**: 文件產包與查詢需要相同且版本可驗證的模型，才能避免產包完成卻無法載入。

**Independent Test**: 下載指定版本後斷網，依既有文件工具的模型相容條件載入並取得有效向量，不需要文件、對話服務或機器人。

**Acceptance Scenarios**:

1. **Given** 模型目的地尚不存在且可連線至公開模型來源，**When** 部署者指定合法固定版本並執行下載，**Then** 完整模型通過離線檢查後才發布，顯示實際版本、位置與完成狀態。
2. **Given** 相同位置已有完整且版本相同的模型，**When** 重複執行相同要求，**Then** 核對檔案後回報已就緒，不重新下載或覆寫。
3. **Given** 已有其他版本或不完整模型，**When** 未明確要求替換，**Then** 拒絕覆寫並告知原因；明確替換時，新模型驗證失敗不得改動既有模型。
4. **Given** 下載中斷、空間不足、版本不存在或必要檔案缺失，**When** 無法完成準備，**Then** 明確失敗，不把半成品當可用模型，不改用其他版本或模型。

---

### User Story 2 - 將唯一文字文件產成 App 可讀的完整包 (Priority: P1)

部署者提供一份 TXT／Markdown、文件識別資訊與已校準門檻，手動執行離線產包腳本，取得含原文與真實定位的索引包，不必手工編輯包資訊或操作索引資料庫。

**Why this priority**: 補齊現有文件工具缺少的素材準備步驟，讓使用者能以指定文件進入既有驗收流程。

**Independent Test**: 使用完整本機模型與無敏感資料的固定文件，在禁止對外連線的環境產包；由既有讀取端驗證並查回可核對的原文與位置。

**Acceptance Scenarios**:

1. **Given** 有效文字文件、本機模型及必要文件資訊，**When** 執行產包，**Then** 取得符合既有 v1 合約的完整包，只包含該文件版本，原始文件與模型不被修改。
2. **Given** 文件含繁體中文、否定條件、表格、程式碼、超連結或操作指令，**When** 切段與產包，**Then** 原文可逐段核對，文字不被執行、翻譯、讀取連結或當作額外授權。
3. **Given** 文件沒有頁碼，**When** 產生定位，**Then** 使用原始行範圍；Markdown 可附原有章節名稱，不編造頁碼。
4. **Given** 相同來源 bytes、識別資訊與切段設定，**When** 產包兩次，**Then** 段落內容、順序、ID 與定位一致，不要求索引二進位逐位相同。
5. **Given** 模型缺失或不相容、缺必要門檻、文件無有效文字或編碼無效，**When** 執行產包，**Then** 明確失敗，不連網下載、不改動既有包、不降低既有讀取端驗證要求。

---

### User Story 3 - 安全發布素材並交接給 App (Priority: P2)

部署者在 App 停止時發布新素材，知道已完成及未完成的驗證，並依腳本顯示的路徑手動設定既有文件工具。

**Why this priority**: 保留已可用的素材，避免將半成品或尚未驗證的平台誤當成已就緒版本。

**Independent Test**: 以既有目的地測試拒絕覆寫、明確替換及失敗／中斷情境；不需啟動實際對話。

**Acceptance Scenarios**:

1. **Given** 從不同工作目錄啟動，**When** 使用預設目的地完成準備，**Then** 素材仍位於儲存庫約定位置，顯示既有兩個路徑設定的實際值，不修改 `.env`。
2. **Given** 包已存在，**When** 未要求替換，**Then** 拒絕覆寫；明確替換時先通過候選包檢查，再發布完整新包。
3. **Given** 候選包無法通過重新開啟、查詢或不變性檢查，**When** 檢查結束，**Then** 不發布為可用包、不標記完成，不修改讀取合約掩蓋問題。
4. **Given** 只在 Windows 完成驗證，**When** 發布相容資訊，**Then** 只列實際通過的 Windows／架構組合，不把略過的 Linux／macOS 寫成已驗證。

### Edge Cases

- 空白／無有效文字、無效 UTF-8、UTF-8 BOM、CRLF／LF、大小寫副檔名；不支援的格式、資料夾、萬用字元、多文件及 URL。
- 超長單段、重複章節、沒有標題、表格及程式碼；Markdown 的外部連結、圖片、HTML 與嵌入指令。
- 浮動模型版本、必要檔案缺失／損壞、不支援檔案或連結、下載暫存資料，以及無可證明的模型 revision。
- 下載中斷、離線卻缺模型、空間不足、權限不足、突然終止及同目的地並行準備。
- 已存在但未允許替換的目的地、來源／模型／輸出互相重疊、根目錄或連結轉向；App 仍在使用素材。
- 索引無法完整持久化、套件版本不相容、缺已校準門檻，或將模型載入成功誤當成文件品質與語音驗收通過。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 提供分開由部署者手動執行的模型下載與單文件離線產包腳本；不在 App 啟動、對話、Tool 或故障修復流程自動執行，不新增管理頁面。
- **FR-002**: 下載只支援現有讀取端接受的 `BAAI/bge-m3`，要求明確的 40 位 commit revision；拒絕浮動分支、tag、其他模型及任意下載 URL。僅下載階段允許連線至公開模型來源及其必要檔案服務，不自動換模型或版本。
- **FR-003**: 下載須供應現有讀取端所需的完整安全權重、tokenizer 與配置，排除不被接受的格式、連結及下載暫存資料。發布前以無網路、無遠端程式碼的條件驗證可依既有 CPU 編碼條件載入並產生合規向量；附可離線核對的模型 ID、不可變 revision 與檔案完整性資訊供產包使用，不只相信資料夾名稱。相同完整版本重跑時核對後直接回報就緒，不重新下載。
- **FR-004**: 預設模型及包位置分別為儲存庫的 `external_content/bge-m3-model/`、`external_content/document-package/`，不隨啟動工作目錄漂移；允許明確指定其他本機目的地。完成時顯示實際位置及既有路徑設定值，不修改 `.env`、一般設定或憑證庫。
- **FR-005**: 產包只接受一份 `.txt`、`.md` 或 `.markdown` 本機常規檔案，副檔名不分大小寫；接受 UTF-8 及 UTF-8 BOM，其他編碼拒絕，不自動轉碼。拒絕其他格式、目錄、批次、多文件及 URL，不展開連結、圖片、HTML 或外部內容。
- **FR-006**: 產包要求文件 ID、顯示名稱、文件版本、索引版本與使用者提供的已校準距離門檻，依既有合約驗證；缺漏／無效時失敗，不把任意預設值宣稱為校準結果。來源摘要依指定原始檔案 bytes 計算，來源檔不被改動。
- **FR-007**: 切段保留原文、順序、可重現的安全 ID 及真實原始行範圍；不翻譯、改字體、重寫或編造定位。超長內容分段而非靜默截斷，預設每段不超過 512 個模型 tokens；切段及上下文重疊的確切規則須固定並文件化，同一設定可重現。Markdown 章節名稱只能取自來源，無頁碼不生成頁碼。
- **FR-008**: 產包全程使用已準備且 revision／完整性可驗證的本機模型，沿用既有 CPU 編碼相容條件；缺模型或不相容時失敗。禁止下載、雲端嵌入、替代模型與對外傳送文件、段落、問題或向量。
- **FR-009**: 產出完整符合既有 [索引包 v1 合約](../004-single-document-rag/contracts/index-package.md) 及 [完整 schema](../004-single-document-rag/contracts/index-manifest.schema.json)：唯一文件版本與集合，包含原文、定位、向量、完整引擎檔案、實際完整套件版本、檔案清單與雜湊。產生固定非敏感 reference 問題及對應向量，驗證編碼一致性；它不代表門檻或回答品質已校準。不修改現有 schema 或 loader 來掩蓋不相容。
- **FR-010**: 候選包須通過獨立重新開啟、查詢及不變性驗證後才發布。檢查須證明原包、原文、定位、向量、筆數及持久檢索索引沒有被讀取端變更，無待重放寫入、修復或重建；只列入實際驗證的平台／架構，不以程序退出或完整性宣告代替證據。
- **FR-011**: 模型及索引目的地預設不得覆寫，明確要求替換才可處理；先驗證候選素材，再發布。可處理的下載、驗證及寫入失敗須保留既有可用版本；突然終止不得把半成品宣告完成，須能辨認殘留並提供恢復／清理指引。只處理本次擁有的暫存，不刪無關內容；同目的地並行準備須拒絕。
- **FR-012**: 拒絕來源文件、產包所用模型與輸出間的危險重疊、不應替換的根目錄及連結轉向；FR-011 明確允許的目的地版本替換不在此拒絕範圍。部署者在 App 停止時替換素材，腳本不得自行停止、啟動或喚醒 App／機器人。
- **FR-013**: 使用繁體中文顯示完成、已就緒、拒絕覆寫、缺必要資料及操作失敗，並以可判別的成功／失敗結果結束。診斷不輸出文件全文、向量、憑證或私密例外內容；命令列可顯示使用者指定的來源／目的地及安全摘要。不讀日常 `.env` 或憑證庫，不要求 HF／Gemini 對話金鑰。
- **FR-014**: 根 README 說明準備順序、必要輸入、位置、替換及恢復方式；沿用既有 rag 依賴與鎖檔，不新增框架。不改變既有 Tool 介面、HF 預設、供應商選擇、相機／記憶權限或一般對話行為。

### Key Entities *(include if feature involves data)*

- **模型準備要求**：指定 BGE-M3 revision、目的地及是否明確允許替換。
- **可驗證本機模型**：模型識別、不可變版本、必要檔案及完整性資訊，附離線載入檢查結果，供產包與既有查詢共用。
- **指定文字文件**：唯一來源 bytes、識別資訊及來源摘要。
- **來源段落**：可重現的 ID、順序、原文、原始行範圍及選擇性的來源章節名稱。
- **候選／已發布索引包**：既有 v1 格式，包含索引版本、編碼相容資訊、使用者提供的門檻、reference 及實際驗證平台。
- **準備結果**：完成／已就緒／失敗狀態、目的地、安全摘要及必要的殘留處理指引；不等同整個 RAG 功能結案。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在文件化的正常案例中，部署者以兩個手動啟動步驟取得完整可載入素材，100% 無須自行搬移模型檔、編輯包資訊或修改私密設定；不包含事前環境安裝及後續 App 啟用。
- **SC-002**: 至少五份有效單文件案例涵蓋中文、英文、否定條件、表格及程式碼／連結，100% 通過素材驗證；所有取回段落可對照原文與位置，沒有其他文件內容。
- **SC-003**: 編碼無效、格式不支援、模型／版本不符、必要檔案損壞、下載中斷、禁止覆寫、危險目的地及發布前驗證失敗至少八類情境，100% 明確拒絕或失敗，無半成品被標記完成；可處理失敗後既有素材與原文件內容變更次數為零。
- **SC-004**: 已就緒素材斷網產包與驗證時對外連線次數為零；重複準備相同且完整的模型時，下載與覆寫次數均為零。
- **SC-005**: 每個已發布包都能由既有讀取端開啟、查詢並核對不變性，通過比例 100%；所有宣告已驗證的平台均有實測紀錄，不把略過平台計入成功。
- **SC-006**: 同一來源與設定重建至少兩次，段落內容、ID、順序及定位一致比例為 100%；診斷中的文件全文、向量及憑證洩漏次數為零。

## Assumptions

- 這是個人客製化的新準備工具功能，承接 004 讀取合約，不代表 004 尚未完成的真實索引、CPU 效能、雙後端品質及現場驗收已通過。
- 「指定模型」是現有 loader 支援的 BGE-M3 指定不可變版本，不擴充為任意模型下載器；公開模型不需要日常對話憑證，下載由使用者明確執行腳本時授權。
- 預設位置沿用儲存庫既有 external_content，實際文件／模型／索引不加入 Git。產包接受下載腳本準備或具同等可驗證來源與完整性資訊的本機模型，不探測私人模型快取。
- 文件及模型供應者由部署者信任，不提供任意不可信檔案沙箱；TXT／Markdown 皆視為文字，不執行其中指令、HTML、程式碼或連結。
- UTF-8 BOM 只供解碼辨識；原始 bytes 摘要仍含原有 BOM，行尾與引用不被改寫。Markdown 保留原始文字，沒有轉成 HTML 或去除語法的需求。
- 使用者提供已校準門檻；不新增自動校準、reranker、多文件、增量更新、PDF／Word 解析或 OCR。reference 是固定非敏感問題，不需私密內容。
- 大小受主機資源限制，不承諾未量測的下載／產包時間或 RAM 上限；資源不足明確失敗，不換模型、降精度或省略段落。
- 本次本機驗收以 Windows／Python 3.12 為範圍；Linux／macOS 不安排實測，保留未驗證限制。程式仍遵守專案跨平台要求，既有 CI 不變。
- 替換前由部署者停止 App；不新增背景服務、執行中替換、上傳頁面或 App 行程控制。錯誤不觸發其他模型、文件或供應商的替代流程。
- 本階段只建立規格，不執行模型下載、文件處理、雲端對話或機器人操作；實際素材與文件段落外送範圍在驗收時另依既有流程確認。
